# N빵 계산기 🧾

친구들과 여행에서 쓴 돈을 적으면, **누가 누구에게 얼마 보내면 끝나는지**를 송금 횟수가 가장 적게 계산해 주는 휴대폰용 웹사이트입니다.

## 할 수 있는 것
- 여행마다 함께 간 사람 이름 적기
- 지출 추가: 내용, 금액, 낸 사람, 나눌 사람(기본 전원, 일부만 선택 가능)
- 유로(EUR)·원화(KRW) 섞어 쓰기 — 환율은 직접 입력
- 최소 송금 정산 결과 + 사람별 낸 돈·쓴 돈 요약
- 카카오톡에 붙여 넣기 좋은 글로 한 번에 복사
- 여행 여러 개 저장하고 다시 열기

## 개인정보
기록은 **그 기기 브라우저(localStorage)에만** 저장됩니다. 서버·데이터베이스가 없고, 입력한 내용을 어디에도 보내지 않습니다.

## 계산 방법
1. 금액은 정수(센트·원)로만 계산하고, 나눌 때 생기는 1센트·1원 나머지는 앞사람부터 하나씩 나눕니다.
2. 사람별 차액(낸 돈 − 쓴 돈)을 구합니다.
3. 차액의 합이 0이 되는 묶음을 가장 많이 찾습니다. 송금 횟수 = 차액이 있는 사람 수 − 묶음 수 (가능한 최소).
